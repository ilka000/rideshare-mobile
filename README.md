# RideShare · Java 3

A small Next.js App Router demo of fictional rides to AAB. It has a trip list, trip details, and a simulated seat request. No booking is sent or stored.

## Run locally

Install Node.js, then run `npm install` and `npm run dev` in this directory. Open the address printed by the terminal, usually http://localhost:3000.

## Routes

- `/` — three fictional trips
- `/udhetimi/2` — trip details and meeting point
- `/udhetimi/2/kerkesa` — pending request simulation
- `/udhetimi/99` — trip not found
