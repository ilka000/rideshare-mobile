# Java 5 · RideShare

Plotësoje pas provave reale. Mos vendos sekrete ose vlera nga `.env.local` këtu.

## Prova 1 · Sesioni

Hyrja me GitHub funksionoi dhe paneli shfaqi profilin. Rifreskimi dhe dalja nuk u provuan.

## Prova 2 · Ndryshimi i lejuar (udhëtimi ID 2)

Në Neon, kushti i pronarit lejoi ID 2: ora u bë 08:25 dhe u rikthye në 08:15. Lista dhe detajet në shfletues nuk u verifikuan.

## Prova 3 · Ndryshimi i refuzuar (udhëtimi ID 1)

Në Neon, i njëjti kusht pronësie nuk lejoi ID 1 (0 rreshta të ndryshuar); ora mbeti 08:00. Ndryshimi i formularit në DevTools nuk u provua.

## Vështirësi ose gabime

Provat e rifreskimit/daljes dhe DevTools kërkojnë veprim në shfletues; verifikimet e lejuara/refuzuara u kryen drejtpërdrejt në Neon.
